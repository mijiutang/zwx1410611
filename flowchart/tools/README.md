# 约束配置编辑器

这是一个独立的约束配置编辑器，用于创建、编辑和管理字段约束配置文件。

## 功能特点

- 自动扫描并加载 `.cache` 目录下的所有YAML约束文件
- 直观的表格界面，显示所有字段约束
- 添加、编辑、删除字段约束
- 支持多种约束类型：
  - 必填字段验证
  - 字符长度限制
  - 正则表达式验证
  - 预定义选项验证
  - 自定义错误消息
- 统一的配置文件格式，确保一致性

## 使用方法

### 方法一：使用批处理文件（推荐）
1. 双击 `启动约束编辑器.bat` 文件
2. 程序将自动启动并扫描 `.cache` 目录中的YAML文件

### 方法二：使用Python脚本
1. 打开命令提示符
2. 导航到工具目录：`cd C:\Users\1\Desktop\workfast\zwx1410611\flowchart\tools`
3. 运行脚本：`python run_constraint_editor.py`

### 方法三：直接运行主程序
1. 打开命令提示符
2. 导航到工具目录：`cd C:\Users\1\Desktop\workfast\zwx1410611\flowchart\tools`
3. 运行主程序：`python constraint_editor.py`

## 操作说明

1. **选择约束文件**：从下拉框中选择要编辑的约束文件（程序会自动扫描 `.cache` 目录）
2. **刷新文件列表**：点击"刷新"按钮重新扫描目录中的YAML文件
3. **添加约束**：点击"添加约束"按钮，在弹出的对话框中设置字段约束
4. **编辑约束**：在表格中选择要编辑的约束，点击"编辑约束"按钮
5. **删除约束**：在表格中选择要删除的约束，点击"删除约束"按钮
6. **保存文件**：点击"保存"按钮保存当前文件，或点击"另存为"按钮保存为新文件

## 约束配置格式

编辑器使用统一的配置格式，保存的YAML文件结构如下：

```yaml
字段名称:
  type: string
  required: true/false
  description: 错误消息
  min_length: 最小长度（可选）
  max_length: 最大长度（可选）
  pattern: 正则表达式（可选）
  pattern_description: 正则表达式描述（可选）
  options: [选项1, 选项2, ...]（可选）
```

## 注意事项

- 编辑器会自动将不同格式的约束文件转换为统一格式
- 所有保存的文件都将使用统一的格式，确保一致性
- 建议在编辑前备份原始约束文件
- 支持的文件格式：.yaml, .yml, .json
